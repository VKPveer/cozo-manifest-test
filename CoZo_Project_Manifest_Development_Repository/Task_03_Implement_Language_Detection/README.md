# Task 03 - Implement Language Detection


## Objective

Detect programming language from source file extensions.


## Implemented Features

Supported Languages:

- Python
- JavaScript
- TypeScript
- Java
- C#
- C++
- Go
- Rust
- PHP


## Input

file_inventory.json


## Output

language_updated_inventory.json


Example:

app.py
    ↓
Python


app.js
    ↓
JavaScript


## Unknown Handling

Unsupported extensions are marked as:

Unknown
