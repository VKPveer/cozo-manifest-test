# Task 01 - Define Project Manifest Schema


## Objective

Define the structure of `project-manifest.json`
which will store a machine-readable representation
of a software codebase.


## Deliverables


### 1. manifest-schema.json

Defines the rules and structure of the manifest.

Contains:

- Repository metadata
- Source files
- Programming languages
- Classes
- Methods
- Functions
- Imports
- Traceability


### 2. project-manifest.json

Example manifest instance.

Contains:

- Repository information
- Code file information
- Class and method details
- Requirement/User Story/Task mapping


### 3. schema-design-notes.md

Documentation explaining:

- Manifest purpose
- Data structure
- Future extensions


### 4. validate_manifest.py

Python validation utility.

Checks:

- JSON correctness
- Schema compliance
